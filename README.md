# Stack-Based Mathematical Expression Evaluator

## 1. Introduction

This project is a Python program developed for the Data Structure and Algorithm assignment. It reads mathematical expressions from an input text file, evaluates them using a stack-based approach, and writes the calculated results to an output text file.

## 2. Objectives

The objectives of this project are to:

* Implement a Stack class.
* Perform stack operations using push, pop, and peek.
* Evaluate mathematical expressions using stacks.
* Apply operator precedence and handle parentheses.
* Read expressions from `input.txt`.
* Write evaluated results to `output.txt`.

## 3. Project Files

The project contains the following files:

* `main.py` — Contains the Python source code.
* `input.txt` — Contains the mathematical expressions to be evaluated.
* `output.txt` — Stores the results generated by the program.
* `README.md` — Provides instructions and information about the project.

## 4. Requirements

Python 3 must be installed on the computer.

No additional Python libraries are required.

## 5. How to Run the Program

1. Place `main.py` and `input.txt` in the same folder.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Run the following command:

   `python main.py`

5. The program evaluates the expressions and saves the results in `output.txt`.

6. Open `output.txt` to view the results.

## 6. Input File Format

The input file is named `input.txt`. Each mathematical expression must appear on a separate line. Separator lines consisting of hyphens are preserved in the output file.

Example:

```
3 + 5
---
10 - 4
---
(8 + 7) * 4
```

## 7. Output File Format

The output file is named `output.txt`. It contains the calculated results on separate lines while preserving separator lines.

Example:

```
8
---
6
---
60
```

## 8. Data Structure Used

The program uses a stack data structure that follows the Last In, First Out (LIFO) principle.

The Stack class implements the following operations:

* `push()` adds an item to the stack.
* `pop()` removes and returns the top item.
* `peek()` returns the top item without removing it.
* `is_empty()` checks whether the stack is empty.

Two stacks are used during expression evaluation: one stores numbers, and the other stores mathematical operators.

## 9. Supported Operations

The program supports addition (+), subtraction (-), multiplication (*), division (/), and parentheses. It applies operator precedence so that multiplication and division are evaluated before addition and subtraction.

## 10. Assumptions and Limitations

* Expressions should contain spaces between numbers and operators.
* The current implementation supports whole-number operands.
* Division by zero is detected.
* Parentheses must be correctly matched.
* Separator lines must consist entirely of hyphens.
* Decimal operands and unary negative numbers are not supported in this version.

## 11. Conclusion

This project demonstrates how stack data structures can be used to evaluate mathematical expressions. It also demonstrates file handling in Python by reading expressions from an input file and writing the results to an output file.
